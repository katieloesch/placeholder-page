# Placeholder Page

## 1. Description

A temporary landing page for a website that is being rebuilt. It lets visitors know that new work is on its way.

## 2. Features

- Responsive layout for desktop and mobile screens
- Under-construction illustration
- Accessible page structure, including a descriptive image alternative

## 3. Technologies and Tools

### Built with

- **HTML** for the page content and semantic structure
- **CSS** for the layout, visual design and responsive breakpoint

## 4. Launching project

The page is static and has no package installation or build step.

1. Clone the repository:

   ```zsh
   git clone https://github.com/katieloesch/placeholder-page.git
   cd placeholder-page
   ```

2. Open `index.html` in a browser or start a local server from the project directory:

   ```zsh
   python3 -m http.server 8000
   ```

   Then visit <http://localhost:8000>.
